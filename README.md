# rize-backend-dev-workspace
Hi! My name is Aaron McCurry, and this is my github repository for the Rize backend development course.

The goal of this repository is to track projects, ideas, and reference materials from this class.

## Overview
This repository is divided into a few key sections:
- Unit Directories: These directories store projects and assignments for each unit of the course
- git-reference.md: This file serves as a "cheatsheet" for common git commands
- learning-log.md: This file is for documenting my backend development goals
- resources.md: A place to store links and other resources that may come in handy later on

I plan to use this repository throughout the semester to keep track of my progress, save my work, and have a place to track my questions and ideas.

## Learning Objectives
My primary learning objective for this course is to *gain a greater understanding of backend applications in order to apply this knowledge to the realm of cybersecurity*. I believe to secure applicaions, you need to understand how they work.
